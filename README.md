# iTech - iPhone 17 Sky Blue Checkout

A modern Apple-inspired checkout page built as a front-end UI demonstration using a single HTML file.

## Features

- Apple-inspired Sky Blue design
- Responsive layout
- Interactive storage selection
- Dynamic order summary
- South African Rand (ZAR) pricing
- Smooth animations
- Pure HTML, CSS and JavaScript (single file)

## Usage

1. Download the project.
2. Open the HTML file in your web browser.

No installation or dependencies are required.
